# Cools 蓝宝石单一光域计算

## 超越 CPO：从 GPU–HBM 封装到数据中心的一个光域

> **Co-Packaged Optics（CPO，共封装光学）只是把电–光转换移到芯片附近。**  
> **Cools 删除反复出现的转换边界，把封装、主板、背板、机架和数据中心连接成一个光学网络。**

[English](README.md) · [한국어](README_KR.md)

## 战略主张

当前数据需要反复跨越 GPU 电接口、封装布线、SerDes、光引擎、光纤和交换机。每一个边界都增加功耗、延迟、面积、对准和封装复杂度。

Cools 改变系统层级：

```text
蓝宝石垂直光封装
→ 自由空间光耦合
→ 光 mesh 主板
→ 光背板
→ 光机架
→ 数据中心光网络
```

> **光信号一直保持为光，直到最终接收光探测器。**

这不是更快的光模块，而是新的计算架构。

---

## 蓝宝石成为系统核心

单晶蓝宝石同时作为：

- 双面异质集成机械载体；
- 宽带光传输介质；
- Through-Sapphire Via（TSaV，贯穿蓝宝石通孔）的绝缘本体；
- 双面光阵列的对准基准；
- GaN 光源外延基板；
- 垂直供电平台；
- 双面散热结构；
- 面向主板的光发射界面。

> **不要把蓝宝石当成生长后要移除的临时基板。把它变成封装的光学、电气和机械骨架。**

---

# 1. GPU–HBM 垂直光封装

GPU 与 High Bandwidth Memory（HBM，高带宽存储器）位于蓝宝石载体的两面。

```text
GPU / AI 加速器
↓ 蓝宝石厚度方向光通道
单晶蓝宝石载体
↓
HBM 基础芯片 / HBM 堆栈
```

- 高速数据：蓝宝石厚度方向光通道；
- 电源与低速控制：TSaV；
- 光区与电区：平面分离；
- GPU 与 HBM 热量：向两面分散；
- 数据路径：从横向毫米级缩短为厚度方向微米级。

> **通过改变互连方向来突破 memory wall，而不是继续压缩横向电布线。**

---

# 2. GaN 光源保留在蓝宝石上

传统 micro-LED 在蓝宝石上生长后通过 Laser Lift-Off（LLO）或微转移移至其他基板。

Cools 保留蓝宝石，使原始外延基板直接成为光封装。

```text
GaN / InGaN micro-LED 阵列
↓ 直接外延集成
蓝宝石光传输介质
↓ 一对一厚度方向光通道
光探测器阵列
```

由此减少或删除：

- LLO；
- 数千发光像素的微转移；
- 独立光波导芯片；
- 独立光轴对准框架；
- 附加中介层。

> **在蓝宝石上生长光源后，不再丢弃光封装中最有价值的部件。**

---

# 3. 背面宽禁带 IVR

GaN 或 SiC Integrated Voltage Regulator（IVR，集成电压调节器）直接结合在蓝宝石另一面。

```text
AI 加速器核心
↑ 通过 TSaV 的短垂直供电路径
蓝宝石载体
↑
背面 GaN / SiC IVR
```

该结构面向：

- 缩短 IVR–核心距离；
- 降低 IR drop 和动态 voltage droop；
- 降低路径电感；
- 宽禁带器件高频开关；
- 缩小电感和电容；
- AI 芯片与 IVR 双面热分离；
- 双面冷却。

> **数据以光穿过蓝宝石，电源通过绝缘 TSaV 垂直传输，热量从两面排出。**

---

# 4. 模块到主板的单一光域

蓝宝石模块通过受控自由空间间隙与光 mesh 主板非接触耦合。

```text
模块光波导
→ 光栅 / 微透镜
→ 自由空间间隙
→ 主板光栅
→ 主板光波导矩阵
```

该间隙同时可用于：

- 光耦合；
- 吸收热膨胀系数差；
- 容纳主板翘曲；
- 隔离振动与机械应力；
- 模块拆卸和更换；
- 消除数据路径 BGA 焊点。

> **封装边界不再必须是光–电转换边界。**

---

# 5. 光 mesh 主板与动态拓扑

主板结合 DWDM、总线波导、波长选择 add/drop、空间通道和模块组标签，实现逻辑 all-to-all 连接，而无需为每一对模块制造独立波导。

光开关可根据工作负载在运行时改变拓扑：

| 工作负载 | 拓扑方向 |
|---|---|
| AllReduce / AllGather | Ring |
| Attention / All-to-All | Mesh 或定制网络 |
| Pipeline parallelism | Chain |
| Broadcast / Aggregation | Tree |
| 多租户 | 独立光组 |

> **工作负载不再适应固定网络，光网络适应工作负载。**

---

# 6. 统一光内存池

每个模块的 HBM 被映射到统一硬件全局地址空间。

系统支持通过光 mesh 发出：

- READ；
- WRITE；
- ATOMIC。

架构覆盖模块 ID 地址转换、波长和空间路由标签、光内存数据包、一致性模型、远程 atomic 操作及多租户硬件隔离。

> **不要在孤立的 GPU 内存之间搬运数据。把所有 HBM 变成一个可寻址的光内存池。**

---

# 7. 同一光网络传输数据、内存和时间

同一光 mesh 分配飞秒至皮秒级光时钟脉冲，并通过模块级光延迟校正和 PLL 生成 GPU、HBM 和 I/O 时钟。

> **一个光网络同时传输数据、内存事务和同步它们的时间基准。**

---

# 8. 从主板扩展至数据中心

```text
蓝宝石模块
→ 光 mesh 主板
→ 光背板
→ 光机架
→ 数据中心光拓扑
```

专利组合包括主板–背板光耦合、机架 Optical Circuit Switch（OCS）、光放大、spine-leaf、fat-tree、dragonfly 拓扑以及分层光路由标签。

> **CPO 在封装边缘结束，Cools 把光域延伸到整个数据中心。**
