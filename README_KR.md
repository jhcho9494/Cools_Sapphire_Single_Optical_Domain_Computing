# 쿨스 사파이어 단일 광 도메인 컴퓨팅

## CPO를 넘어: GPU–HBM 패키지에서 데이터센터까지 하나의 광 도메인

> **Co-Packaged Optics(CPO, 동시패키지광학)는 전기–광 변환 위치를 칩 가까이 옮깁니다.**  
> **쿨스는 반복되는 변환 경계 자체를 제거하고 패키지·마더보드·백플레인·랙·데이터센터를 하나의 광 패브릭으로 통합합니다.**

[English](README.md) · [中文](README_ZH.md)

---

## 전략적 제안

다음 컴퓨팅 장벽은 트랜지스터 집적도만이 아닙니다. 연산·메모리·전력·클럭·네트워크가 서로 다른 계층으로 분리되어 있다는 점이 병목입니다.

현재 데이터는 다음과 같이 반복적으로 경계를 통과합니다.

```text
GPU 전기 I/O
→ 패키지 배선
→ SerDes
→ 광엔진
→ 광섬유
→ 스위치
→ 다른 광엔진
→ 다른 SerDes
→ 다른 GPU 또는 메모리
```

경계마다 변환전력·지연·면적·정렬·패키징 부담이 추가됩니다.

쿨스는 구조를 바꿉니다.

```text
사파이어 수직광 패키지
→ 자유공간 광결합
→ 광 mesh 마더보드
→ 광 백플레인
→ 광 랙
→ 데이터센터 광 패브릭
```

> **광신호는 최종 수신 광검출기에 도달할 때까지 광 상태를 유지합니다.**

이것은 더 빠른 광모듈이 아니라 컴퓨팅 위계 자체의 재설계입니다.

---

## 사파이어 핸들러가 시스템의 중심이 됩니다

단결정 사파이어 한 부재가 동시에 수행하는 기능입니다.

- 양면 이종집적용 기계적 핸들러
- 광대역 광전송 매질
- Through-Sapphire Via(TSaV, 관통 사파이어 비아)의 절연 모체
- 양면 광어레이의 결정학적 정렬 기준
- GaN계 광원의 에피택시 성장기판
- 두께 방향 전력전달 기판
- 양면 열분산 구조
- 마더보드로 향하는 광 출사 인터페이스

> **사파이어를 임시 성장기판으로 사용한 뒤 제거하지 않습니다. 패키지의 광·전력·기계 중심부로 전환합니다.**

---

# 1. GPU–HBM 두께 방향 광 패키지

종래 GPU–High Bandwidth Memory(HBM, 고대역폭 메모리) 패키지는 인터포저 위에 GPU와 HBM을 수평 배치합니다. 가장 먼 연결은 여전히 밀리미터에서 센티미터급이며, 배선면적·손실·누화·전력 문제가 누적됩니다.

쿨스는 GPU와 HBM을 사파이어 핸들러의 양면에 배치합니다.

```text
GPU / AI 가속기
↓ 사파이어 두께 방향 광채널
단결정 사파이어 핸들러
↓
HBM 베이스 다이 / HBM 스택
```

- 고속 데이터: 사파이어 두께 방향 광채널
- 전력·저속 제어: TSaV
- 광 영역과 전기 영역: 평면상 분리
- GPU 열과 HBM 열: 양면으로 분산
- 데이터 경로: 수평 밀리미터급에서 두께 방향 수백 마이크로미터급으로 단축

> **메모리 월을 더 미세한 수평배선이 아니라 연결 방향의 전환으로 공격합니다.**

---

# 2. GaN 광원을 사파이어에서 떼어내지 않습니다

종래 마이크로 발광 다이오드(μLED)는 사파이어 위에서 성장한 뒤 Laser Lift-Off(LLO, 레이저 리프트오프) 또는 마이크로 전사로 다른 기판에 옮깁니다.

쿨스는 사파이어를 제거하지 않고 패키지 자체로 사용합니다.

```text
GaN / InGaN μLED 어레이
↓ 사파이어 위 직접 에피택시
사파이어 광전송 매질
↓ 두께 방향 일대일 광채널
광검출기 어레이
```

사파이어 한 장이 다음을 모두 담당합니다.

- GaN 에피택시 성장면
- 두께 방향 광매질
- 양면 정렬기준
- 광검출기 기계 지지체
- 무절연 TSaV의 절연 모체

따라서 다음 의존성을 줄이거나 제거합니다.

- LLO
- 수천 개 μLED의 마이크로 전사
- 별도 광도파로 칩
- 별도 광축 정렬프레임
- 추가 인터포저

> **광원을 사파이어 위에서 성장시킨 뒤, 가장 가치 있는 광학부재인 사파이어를 버리지 않습니다.**

---

# 3. 백사이드 광대역갭 IVR

AI 가속기는 낮은 코어전압과 매우 큰 전류를 요구합니다. 마더보드 측 Voltage Regulator Module(VRM, 전압조정모듈)은 긴 Power Distribution Network(PDN, 전력공급망)를 통해 저전압 대전류를 전달해야 합니다.

쿨스는 GaN 또는 SiC 기반 Integrated Voltage Regulator(IVR, 통합전압조정기)를 사파이어 반대면에 직접 배치합니다.

```text
AI 가속기 코어
↑ TSaV를 통한 수백 마이크로미터 전력경로
사파이어 핸들러
↑
백사이드 GaN / SiC IVR
```

이 구조는 다음을 겨냥합니다.

- IVR–코어 전력경로 단축
- IR drop 감소
- 동적 전압 droop 감소
- 경로 인덕턴스 감소
- 광대역갭 스위치의 고주파 동작
- 인덕터·커패시터 소형화
- AI 다이와 IVR 발열의 양면 분리
- 양면 냉각

> **데이터는 사파이어를 광으로 통과하고, 전력은 절연된 TSaV를 통해 수직 공급되며, 열은 양면으로 빠져나갑니다.**

---

# 4. 모듈에서 마더보드까지 하나의 광 도메인

사파이어 모듈의 광 출사면은 광 mesh 마더보드를 향합니다. 모듈과 마더보드는 솔더 데이터접속 대신 제어된 자유공간 갭으로 광결합됩니다.

```text
모듈 내부 광도파로
→ 그레이팅·마이크로렌즈
→ 자유공간 갭
→ 마더보드 그레이팅
→ 마더보드 광도파로 매트릭스
```

자유공간 갭은 동시에 다음 기능을 수행할 수 있습니다.

- 광결합
- 열팽창계수 차이 흡수
- 마더보드 워피지 수용
- 진동·기계응력 격리
- 모듈 분리·교체
- 데이터용 BGA 솔더 조인트 제거

> **패키지 경계가 더 이상 광–전 변환 경계일 필요가 없습니다.**

---

# 5. 광 mesh 마더보드

마더보드는 광 도파로 매트릭스와 파장 또는 파장–공간 복합 라우팅 구조를 포함합니다.

- 버스 도파로
- Dense Wavelength Division Multiplexing(DWDM, 조밀파장분할다중화)
- 파장선택 add/drop
- 공간채널
- 모듈 그룹 라우팅 라벨

을 결합하여 모든 모듈쌍마다 별도 물리 도파로를 만들지 않고 논리적 all-to-all 연결성을 제공합니다.

광 신호 평면과 전력 평면은 물리적으로 분리됩니다.

---

# 6. 워크로드에 따라 네트워크가 바뀝니다

고정 토폴로지는 모든 워크로드에 동일한 통신구조를 강요합니다.

쿨스는 광 스위치로 런타임 토폴로지를 재구성합니다.

- 마이크로링 공진기
- Mach–Zehnder Interferometer(MZI, 마하–젠더 간섭계)
- Micro-Electro-Mechanical Systems(MEMS, 미세전자기계시스템) 거울
- Phase Change Material(PCM, 상변환물질) 셀

| 워크로드 | 광 토폴로지 방향 |
|---|---|
| AllReduce·AllGather | Ring |
| Attention·All-to-All | Mesh 또는 맞춤형 패브릭 |
| Pipeline parallelism | Chain |
| Broadcast·Aggregation | Tree |
| 다중 테넌트 | 독립 광그룹 |

> **워크로드가 고정 네트워크에 적응하는 것이 아니라, 광 네트워크가 워크로드에 적응합니다.**

---

# 7. 모든 HBM을 하나의 광 메모리 풀로

각 모듈의 HBM을 별도 주소공간이 아니라 하드웨어 글로벌 주소공간에 매핑합니다.

다른 모듈의 HBM에 광 mesh를 통해 다음 트랜잭션을 발행합니다.

- READ
- WRITE
- ATOMIC

포트폴리오는 다음을 포함합니다.

- MODULE_ID 기반 주소변환
- 파장·공간 라우팅 라벨
- 광 메모리 패킷
- strong·release-acquire·weak consistency
- 원격 atomic 연산
- 작업·테넌트 간 하드웨어 격리
- 토폴로지 변경 후 동적 라우팅 테이블 갱신

> **고립된 GPU 메모리 사이에서 데이터를 복사하지 않습니다. 모든 HBM을 하나의 주소 가능한 광 메모리 풀로 만듭니다.**

---

# 8. 데이터·메모리·시간을 하나의 광 패브릭으로

동일 광 mesh에 펨토초·피코초 광 클럭을 분배하여 모든 모듈의 시간기준을 통합합니다.

- 데이터와 광클럭의 파장분할·별도도파로·시분할 공존
- 모듈별 광 지연 보정
- 광검출 후 Phase-Locked Loop(PLL, 위상잠금루프) 기반 클럭 도출
- GPU·HBM·I/O 공통 시간기준

> **하나의 광 패브릭이 데이터, 메모리 트랜잭션, 그리고 이들을 동기화하는 시간기준까지 전달합니다.**

---

# 9. 마더보드를 넘어 데이터센터까지

```text
사파이어 모듈
→ 광 mesh 마더보드
→ 광 백플레인
→ 광 랙
→ 데이터센터 광 토폴로지
```

포트폴리오는 다음을 포함합니다.

- 마더보드–백플레인 자유공간 또는 광커넥터 결합
- 랙 광 패치패널과 Optical Circuit Switch(OCS, 광회선스위치)
- Erbium-Doped Fiber Amplifier(EDFA), Semiconductor Optical Amplifier(SOA), Raman 증폭
- spine-leaf·fat-tree·dragonfly 광 토폴로지
- 계층적 광 라우팅 라벨
- 동적 토폴로지·광클럭·통합메모리의 데이터센터 확장

> **CPO는 패키지 가장자리에서 끝납니다. 쿨스는 광 도메인을 데이터센터까지 확장합니다.**

## 전체 아키텍처

```text
MONOLITHIC LIGHT
사파이어 위 GaN / InGaN μLED 직접 성장

VERTICAL PACKAGE
GPU ↕ 사파이어 광채널 ↕ HBM

VERTICAL POWER
백사이드 WBG IVR ↕ TSaV ↕ AI 코어

MODULE COUPLING
사파이어 광출사면 ↕ 자유공간 갭 ↕ 마더보드

OPTICAL FABRIC
파장 라우팅 + 동적 광스위칭

GLOBAL MEMORY
모든 HBM의 통합 주소공간

GLOBAL TIME
동일 광패브릭의 펨토초 광클럭

SYSTEM SCALE
마더보드 → 백플레인 → 랙 → 데이터센터
```

## 종래 의존성과 쿨스 방향

| 종래 의존성 | 쿨스 방향 |
|---|---|
| 긴 수평 GPU–HBM 전기배선 | 두께 방향 GPU–HBM 광연결 |
| 별도 광칩렛 | 사파이어 일체형 광원·검출기 어레이 |
| 반복 O/E·E/O 변환 | 연속 단일 광 도메인 |
| 마더보드 측 저전압 VRM | TSaV 직결 백사이드 WBG IVR |
| 고정 전기 토폴로지 | 런타임 재구성 광 토폴로지 |
| 분리된 HBM 주소공간 | 통합 광 메모리 풀 |
| 다단 전기 클럭트리 | 공통 광클럭 분배 |
| 솔더 기반 모듈 데이터접속 | 교체 가능한 자유공간 광결합 |
| 패키지 한정 CPO | 데이터센터급 광 패브릭 |

## 특허 보호 및 거래구조

본 저장소의 기술과 아키텍처는 쿨스의 출원 중 특허 및 관련 비공개 노하우로 보호됩니다.

포트폴리오는 다음 특허축을 포함합니다.

- 사파이어 GPU–HBM 양면 수직광 패키지
- 사파이어 백사이드 WBG IVR
- GaN μLED–광검출기 모놀리식 어레이
- 단일 광 도메인 모듈–마더보드 결합
- 광 mesh 마더보드
- 런타임 광 토폴로지 재구성
- 통합 광 메모리 풀
- 펨토초 광클럭 분배
- 백플레인·랙·데이터센터 확장

협의 가능한 구조:

- 독점·비독점 특허 라이선스
- 제품·노드·분야·지역 제한 실시권
- 공동 아키텍처·공정 개발
- 패키지·보드·데이터센터 통합
- 장비·양산 협력
- 전략적 투자 또는 기술사업 양수도
- 조건이 적합한 경우 관련 특허출원·특허권 자체의 양도·이전

**협상은 단순 라이선스에 한정되지 않습니다. 전략적 목적과 거래조건이 적합하면 관련 특허 포트폴리오 자체도 거래 대상에 포함될 수 있습니다.**

본 저장소의 공개는 실시 허락, 권리 포기 또는 기술사용 승인을 의미하지 않습니다. 구체적 적층구조, 광예산, 채널 형상, 공정흐름, 제어 프로토콜 및 청구항 대비표는 통제된 기술·법률 협의에서 제공합니다.
